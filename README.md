# dynopt

Курс динамической оптимизации, рассказывающий про подходы оптимального управления и оптимизации динамически изменяющихся систем. Выберите год: [2026](https://github.com/AlexeiUjegov/dynopt/tree/year2026).


## Инфоресурсы

Папка seminars содержит задания с семинарских занятий, homweorks -- домашние задания, а freeSolve -- задачи на свободное прорешивание.
