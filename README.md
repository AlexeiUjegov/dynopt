# dynopt

Курс динамической оптимизации, рассказывающий про подходы оптимального управления и оптимизации динамически изменяющихся систем. Издание 2026.

## Инфоресурсы

Папка seminars содержит задания с семинарских занятий, homweorks -- домашние задания, а freeSolve -- задачи на свободное прорешивание.
